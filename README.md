# 🎮 CatchMeIfYouCan

> 경찰과 도둑 컨셉의 멀티플레이 게임으로써 다양한 아이템을 활용해  
> 도둑들은 도망가고, 경찰들은 도둑을 체포하는 게임

---

## 1. 프로젝트 개요 (Overview)

'경찰과 도둑' 컨셉의 멀티플레이 게임 

- **프로젝트명**: CatchMeIfYouCan
- **핵심 컨셉**: 6인 비대칭 멀티플레이 (경찰 vs 도둑) 추격 액션
- **개발 엔진**: Unreal Engine 5.6.1
- **네트워크**: 리슨 서버 (Listen Server)
- **개발 목표**: 핵심 게임플레이 루프(추격 → 근접 공격 → 체포)와 클라이언트-서버 상호작용을 테스트할 수 있는 프로토타입 빌드

## 2. 게임 디자인 (Game Design)

### 게임플레이 루프

매치 로그인 → 팀 분배 →  매치 시작 → 경찰의 추격, 도둑의 금고 털기 → 팀 별 승리조건 충족시 게임 종료

### 핵심 메카닉

- **👮 경찰 (Police)**
    - **이동**: 기본 이동 및 점프, 사다리 타기(도둑보다 더 빠른 기본 이동 속도)
    - **공격**: 곤봉을 이용한 근접 공격
    - **역할**: 맵에 있는 모든 도둑을 찾아내어 아이템 활용 및 곤봉으로 가격해 '체포' 한다.
    - **아이템**: 데미지 트랩, 동결 트랩, 이속 감소 트랩
- **🏃 도둑 (Robber)**
    - **이동**: 기본 이동 및 점프, 사다리 타기
    - **피격**: 경찰의 곤봉에 맞아 체력이 0이 되면 '스턴' 상태가 되고 이때 체포되면 감옥으로 이송
    - **역할**: 경찰의 추격을 피해 최대한 생존하면서 맵에 존재하는 모든 금고를 약탈한다.
    - **아이템**: 힐 포션, 스피드 부스트 포션, 투명화 포션

### 승리 조건

- **경찰 팀**: 제한 시간 내에 모든 도둑을 '체포' 상태로 만들면 승리.
- **도둑 팀**: 제한 시간이 종료될 때까지 한 명이라도 체포되지 않고 생존 하거나 모든 금고 개방

## **3. 팀원 역할 분배**

**김민영** : 인게임 모드 로직, 캐릭터 클래스, 어빌리티 시스템 설계  
**홍승조** : 아이템, 공격 어빌리티 설계  
**안지호** : AI 정찰견  
**고건희** : EOS 로그인 연동  
**곽준상** : 맵 제작 및 레벨 디자인 설계  
**임동휘** : 인게임 UI 위젯 설계

### 향후 확장 아이디어

> 💡 경찰: 특수 무기 (테이저건), 스킬 (일시적 이동 속도 증가)  
> 💡 도둑: 감속 장판 설치  
> 💡 경찰, 도둑 직업군 추가(고유 능력 존재)  
>
> 💡 게임 룰: 도둑에게 목표를 부여하여 일정 시간 내에 목표를 달성하지 못하면 패배하도록 변경 가능
